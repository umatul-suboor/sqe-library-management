# SQE Library Management

## Project Description

The SQE Library Management project is developed as part of the Software Quality Engineering Lab. The project focuses on applying software quality practices using GitHub-based development workflows.

The system is intended to manage books and library members and provide book search functionality.

## Main Features

- Book Management
- Member Management
- Book Search

## Project Structure

- `src/` — Application source code
- `tests/` — Test cases and automated tests
- `docs/` — Project documentation
- `screenshots/` — Evidence of testing and activities
- `.github/workflows/` — GitHub workflow files

## Software Quality Engineering

GitHub Issues, Labels, Projects, testing activities, documentation, and version control are used to support the software quality process.
