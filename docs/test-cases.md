## Test Case Notes

* TC-002, TC-003, TC-005, TC-007, and TC-009 are explicitly negative/error-path tests.
* TC-012 is a boundary-value test.
* The test cases are based on the functional areas specified in the Lab 4 requirements.
* Tests for functionality that is not implemented in the current LibraryHub code will be recorded as **FAIL** or **BLOCKED** during manual execution rather than being incorrectly marked as PASS.
